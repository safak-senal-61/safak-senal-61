Merhaba, ben **Sağak Şenal** 👋
Arka planda REST ve GraphQL servisleri, ön yüzde React/Next.js, mobil tarafta React Native ve Flutter ile uçtan uca ürünler geliştiriyorum. Tek bir teknolojiye takılı kalmak yerine, doğru probleme doğru aracı seçmeyi seviyorum.

- 🔭 Şu an **tam yığın (fullstack) projeler** üzerinde çalışıyorum — hem web hem de mobil istemciler için aynı backend'i konuşlandırıyorum.
- 🌱 Aktif olarak **React Server Components**, **Flutter 3.x** ve **Container-native dağıtım** üzerine öğreniyorum.
- 💬 Bana **React Native + Expo**, **Next.js 16**, **Prisma** ve **FastAPI** konularında sorabilirsin.
- ⚡ Fun fact: Bir kerede 3 farklı istemci (web + iOS + Android) için tek backend yazıp "3x verim" diyorum. ☕
- 📫 Bana ulaşmak için aşağıdaki iletişim bölümüne bakabilirsin.
